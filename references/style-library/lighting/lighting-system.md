## 01. Runway Spotlight — 秀场顶光+追光

**编码**：runway-spotlight
**色温**：5000-5600K（中性偏冷）
**氛围**：专业、力量、戏剧

### 灯光布局
- **主光**：头顶45度强聚光灯，模拟秀场顶光
- **辅助光**：侧面追光灯跟随模特移动
- **轮廓光**：背后逆光勾勒身体轮廓
- **环境光**：烟雾中散射产生体积光效果

### 光影效果
- 面部上半部分明亮，眼窝和颧骨下产生戏剧性阴影
- 身体轮廓在追光中特别突出
- 烟雾中的光束增加空间层次感
- 地面反射光从下方轻微补光

### Prompt 描述词
秀场追光灯效果，头顶45度强聚光灯照射，
侧面追光勾勒身体轮廓，烟雾中光线散射产生体积光，
冷色温专业秀场照明，戏剧性的明暗对比，
地面积水或光面反射底部补光

### 适配
情绪：confident + dominant
服装：全品类（尤其 lace + sportswear）
镜头：35mm全身 + low_angle

## 02. Cinematic Tungsten — 电影暖色钨丝灯

**编码**：cinematic-tungsten
**色温**：2700-3200K（暖黄）
**氛围**：电影感、温暖、叙事

### 灯光布局
- **主光**：侧面大型钨丝灯或模拟钨丝灯LED
- **辅助光**：对面反光板柔和填充
- **轮廓光**：背后暖色LED条勾勒边缘
- **环境光**：低照度暖色氛围

### 光影效果
- 面部侧面光产生伦勃朗三角光
- 暖色调让肤色呈现蜜糖色
- 阴影柔和过渡，电影级色彩
- 高光区域温暖不刺眼

### Prompt 描述词
电影级钨丝灯暖色调照明，侧光照射产生伦勃朗三角光，
暖黄2700K色温，肤色呈现蜜糖色光泽，
阴影柔和过渡如电影画面，高光温暖不刺眼，
暗部保留丰富细节，电影叙事感的光影

### 适配
情绪：luxurious + mysterious
服装：silk + lace（暖色面料效果最佳）
镜头：85mm + 50mm

## 03. Pool Reflection — 泳池水面反光

**编码**：pool-reflection
**色温**：5500-6500K（自然日光+水面蓝色偏移）
**氛围**：度假、自然、波光粼粼

### 灯光布局
- **主光**：自然日光或模拟日光的大型柔光
- **辅助光**：泳池水面反射的波光从下方照射
- **轮廓光**：自然逆光或侧逆光
- **环境光**：水面波光映射到天花板和墙壁

### 光影效果
- 面部均匀受光，水面反射从下方补光消除下巴阴影
- 身体上有水面波光的动态光影图案
- 蓝绿色调的环境光营造水边氛围
- 高光区域有水波纹的动态效果

### Prompt 描述词
泳池水面反射光照明，波光粼粼的动态光影图案投射到皮肤，
水面反射从下方柔和补光，蓝绿色调环境光，
阳光与水面反射的混合照明，水波纹光影流动效果，
自然日光色温偏蓝绿，度假水边的清新光影

### 适配
情绪：playful + confident
服装：swimwear（全品类泳装）
镜头：35mm全身 + low_angle
