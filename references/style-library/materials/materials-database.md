## 01. Liquid Metallic（液态金属）

**编码**：liquid-metallic
**适配**：cyberwear, swimwear-metallic, lace-crystal

### 光影特性
- 高反光镜面效果，像流动的水银
- 光线照射产生明暗交替的液态流动感
- 角度变化导致色彩偏移（银→蓝→紫）

### 褶皱表现
- 褶皱处反光锐利，像折纸的金属面
- 平整处如镜面，反射环境光
- 穿着时随身体曲线产生流动感褶皱

### Prompt 描述词
液态金属面料，镜面反光效果，流动金属光泽，
角度变化产生银蓝紫色彩偏移，褶皱处锐利反光，
如流动水银般包裹身体曲线，高科技未来感材质

## 02. Semi-transparent Silk（半透明真丝）

**编码**：semi-silk
**适配**：silk全品类, lace全品类, nude

### 光影特性
- 柔和透光效果，光线穿透面料形成朦胧光晕
- 逆光时面料边缘发光，呈半透明金色或白色
- 顺光时面料表面有珍珠般柔和光泽

### 褶皱表现
- 褶皱柔和圆润，无锐利边缘
- 面料垂坠自然，形成优雅的瀑布型褶皱
- 随风或动作产生轻盈飘动感

### Prompt 描述词
半透明真丝面料，柔和透光效果，逆光时边缘发光，
珍珠般柔和光泽，褶皱柔和圆润如流水，
轻盈飘逸的垂坠感，光线穿透面料的朦胧美

## 03. Micro Lace Embroidery（微距蕾丝刺绣）

**编码**：micro-lace
**适配**：lace全品类, silk全品类

### 光影特性
- 花纹在光线下产生精致的阴影投射到皮肤上
- 透光部分与不透光部分形成精美对比
- 微距下花纹细节极致丰富

### 褶皱表现
- 蕾丝面料褶皱处花纹重叠，产生层次感
- 刺绣部分硬挺，蕾丝部分柔软，软硬对比
- 贴合身体时花纹随曲线变形，更显精致

### Prompt 描述词
微距蕾丝刺绣面料，精致花纹投射阴影到肌肤，
透光与不透光的精美对比，刺绣细节极致丰富，
花纹随身体曲线变形更显精致，高定工艺级别的面料

## 04. Pearlescent Fabric（珠光面料）

**编码**：pearlescent
**适配**：swimwear, silk, lace-nude

### 光影特性
- 彩虹反光效果，随角度变化呈现不同色相
- 表面有微妙的珠母光泽，像贝壳内壁
- 光线照射时产生温暖的柔光扩散

### 褶皱表现
- 褶皱处珠光集中，产生高光带
- 平整处珠光均匀扩散，整体温润
- 随身体曲线产生渐变色带效果

### Prompt 描述词
珠光面料，彩虹反光效果，随角度变化呈现色相偏移，
贝壳内壁般的珠母光泽，光线照射时温暖柔光扩散，
褶皱处珠光集中产生高光带，温润高级的面料质感

## 05. Latex Gloss（亮面乳胶）

**编码**：latex-gloss
**适配**：cyberwear, swimwear

### 光影特性
- 极高反光，几乎镜面级别的光泽
- 光线照射产生锐利的高光带
- 深色乳胶在光线下呈现深邃的黑曜石质感

### 褶皱表现
- 褶皱锐利如刀刻，边缘清晰
- 贴合度极高，完美复制身体轮廓
- 穿着时产生"第二层皮肤"效果

### Prompt 描述词
亮面乳胶材质，镜面级高反光，锐利的高光线如刀刻，
完美贴合身体轮廓如第二层皮肤，深邃的黑曜石质感，
褶皱锐利清晰，极致的光泽感和包裹感

## 06. Wet Reflective Fabric（湿感反光面料）

**编码**：wet-reflective
**适配**：swimwear, sportswear, cyberwear

### 光影特性
- 模拟湿润状态的反光效果
- 水珠附着在面料表面产生点状高光
- 整体呈现波光粼粼的水面反射感

### 褶皱表现
- 面料因"湿润"产生贴合效果
- 褶皱处积水效果，光线折射
- 表面有水珠滚动的动态感

### Prompt 描述词
湿感反光面料，模拟湿润状态的水面反射效果，
水珠附着表面产生点状高光，波光粼粼的动态质感，
面料因湿润贴合身体曲线，褶皱处光线折射出水感光泽
