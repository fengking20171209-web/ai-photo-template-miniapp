# SkirtDNA 补充 — 透视褶皱连衣裙（Sheer Ruched Bodycon）

> 版本：v1.0 | 创建：2026-05-28 | 核心美学：朦胧透视 + 褶皱质感

---

## 一、为什么这种裙子有效

### 朦胧感 = 高级性感

透视面料（sheer mesh / tulle）的核心效果是 **"若隐若现"**：
- 不是直接裸露，而是通过半透明层制造 **视觉层次**
- 皮肤在网纱下隐约可见，比直接露肤更 **有想象空间**
- 不透明内衬 + 透明外层 = **对比产生的张力**

这和蕾丝的逻辑一样：**遮挡比裸露更性感**。

### 褶皱 = 身材优化器

ruched/gathered 面料的 AI 出图优势：
- 褶皱自然产生 **明暗层次**，让面料看起来有质感
- 横向褶皱 **柔化身体轮廓**，不会像光滑面料那样暴露每一处不完美
- 褶皱在腰部和臀部自然收紧，**视觉上强化腰臀比**
- AI 生成褶皱面料比生成光滑紧身面料 **更稳定**

```

natural facial proportions, fair porcelain skin,

black bodycon mini dress with sheer mesh illusion upper panel,
```

```
choker-style band collar,
```

## 四、搭配方案

### 鞋子

| 风格 | 最佳鞋款 | 效果 |
|------|----------|------|
| 高级晚宴 | 细跟尖头高跟鞋（同色系） | 延伸腿部线条 |
| 日常约会 | 玛丽珍中跟鞋 | 甜美减龄 |
| 夜店派对 | 透明PVC高跟鞋 | 未来感+腿部延伸 |
| 街拍 | 短靴/切尔西靴 | 反差酷感 |

### 配饰

| 配饰 | 效果 |
|------|------|
| 精致项链（填补choker下方空白） | 增加层次 |
| 长耳坠（延伸颈部线条） | 优雅感 |
| 手拿包/链条包 | 晚宴感 |
| 无配饰（极简） | 高冷编辑感 |

### 丝袜

| 选择 | 效果 |
|------|------|
| 裸腿（推荐） | 裙子本身已有层次，丝袜会过度 |
| 超薄裸感丝袜 | 微微光泽，更精致 |
| 不要黑丝 | 与透视元素冲突，整体太暗 |

## 七、AI 生图优化要点

### 核心挑战：透视层次

AI 最容易犯的错是 **把透视层和内衬混为一体**。

必须明确告诉 AI：
```
TWO distinct layers:
1. Outer layer: transparent sheer mesh (shoulders, upper chest, sleeves)
2. Inner layer: opaque solid fabric (bust area, body, skirt)
The mesh should be visibly see-through with skin showing beneath
The opaque layer should be clearly solid and non-transparent
```

### 褶皱密度控制

| 褶皱程度 | 描述词 | 效果 |
|----------|--------|------|
| 密褶皱 | `dense ruching, tightly gathered` | 更显瘦，质感强 |
| 中等褶皱 | `moderate ruching, softly gathered` | 自然，日常 |
| 微褶皱 | `subtle ruching, lightly gathered` | 高级，极简 |

### Negative Prompt（针对此类裙子）

```
smooth surface without texture, flat fabric, no ruching,
fully transparent dress, completely see-through, nudity,
long dress, maxi length, floor length,
loose fit, oversized, baggy,
no mesh panels, no sheer elements,
cheap looking, low quality, plastic skin
```
