# 肚兜 v2.0 — 新中式下装品类定义

> 版本：v2.0 | 创建：2026-05-28 | 替代夜店包臀裙+纯黑丝

---

## 核心原则

肚兜上装 + 新中式高腰短裙 + 柔和薄丝袜 + 高跟鞋 + 团扇/折扇
**不是** 肚兜 + 夜店超短包臀裙 + 纯黑丝

---

## 方案 A：高腰缎面短裙 ⭐最推荐

```
high-waisted satin mini skirt,
soft fitted silhouette,
slightly curved hemline,
refined modern Chinese styling
```

搭配丝袜：烟灰丝·酒红薄丝·珍珠灰丝（按肚兜颜色选）
适合：所有肚兜颜色

---

## 方案 B：高腰开衩铅笔半裙 ⭐最有编辑感

```
high-waisted fitted pencil skirt,
elegant side slit,
smooth body-contouring silhouette,
bare legs or nude sheer stockings,
refined editorial styling
```

搭配丝袜：裸感薄丝或裸腿
适合：米白·象牙白·浅青绿肚兜

---

## 方案 C：短款马面元素半裙 ⭐最融合

```
modernized short mamian-inspired skirt,
structured wrap silhouette,
high waist,
subtle pleated panel detail,
fusion of traditional Chinese and modern fashion
```

搭配丝袜：茶灰丝·裸咖丝
适合：墨绿·深色肚兜

---

## 方案 D：轻薄纱罩层短裙

```
body-hugging mini skirt with sheer overlay,
light translucent outer layer,
soft draped edge,
tone-on-tone sheer stockings,
delicate feminine elegance
```

搭配丝袜：同色系薄丝
适合：绛红·浅色肚兜

---

## 丝袜颜色速查

| 肚兜颜色 | 推荐丝袜 | 不要 |
|----------|----------|------|
| 绛红/酒红 | 烟灰丝·酒红薄丝·暖棕灰丝 | 纯黑丝 |
| 墨绿/孔雀绿 | 茶灰丝·石墨灰丝·裸咖丝 | 纯黑丝 |
| 米白/象牙白 | 裸感薄丝·珍珠灰丝·极浅烟粉丝 | 纯黑丝 |
| 黑金 | 半透明黑灰丝·深葡萄紫丝·深棕黑丝 | 纯厚黑 |
| 浅青绿 | 极浅烟粉丝·裸咖丝 | 纯黑丝 |

## 臀线描述优化词

### 不推荐（直白/易畸变）
~~屁股很翘·臀部很大·很性感的臀线~~

### 推荐（高级/稳定）
```
smooth rounded hip line,
naturally lifted silhouette,
balanced waist-to-hip proportion,
graceful body contour,
elegant feminine curve,
refined body-hugging silhouette
```
