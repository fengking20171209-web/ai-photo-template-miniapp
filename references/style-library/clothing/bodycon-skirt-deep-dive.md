## 一、基础定义与结构分类

### 1.1 什么是包臀裙

包臀裙（bodycon pencil skirt / hip-hugging mini skirt）的核心特征：
- **贴合臀部曲线**：从腰到臀完全贴合身体轮廓
- **膝盖以上**：裙摆在大腿中段或更高
- **无褶裥或少褶裥**：靠裁剪和面料弹性塑形
- **强调腰臀比**：视觉核心是腰部到臀部的S曲线

### 1.2 结构分类（按剪裁方式）

| 类型 | 英文 | 结构特征 | 视觉效果 | 适合场景 |
|------|------|----------|----------|----------|
| **A. 经典铅笔型** | Classic Pencil | 前后两片式，侧缝直线，下摆微收 | 优雅知性，Office 感 | 职场、正式场合 |
| **B. 鱼尾型** | Mermaid/Fishtail | 臀部贴合，膝部以下展开 | 优雅性感，走秀感 | 晚宴、红毯 |
| **C. 包裹型** | Wrap | 前片交叉包裹，系带或暗扣固定 | 不对称美感，层次感 | 日常、约会 |
| **D. 开衩型** | Slit | 侧开衩或前开衩，行走时露出腿部 | 性感中带克制 | 酒会、夜景 |
| **E. 拼接型** | Color-block/Panel | 多片式拼接，不同面料或颜色 | 几何感，设计感强 | 时装秀、街拍 |
| **F. 弹力一体型** | Seamless Tube | 无缝圆筒弹力面料，无侧缝 | 极简现代，运动感 | 运动休闲、极简风 |
| **G. 高腰A字型** | High-waist A-line | 高腰线，微A字展开 | 甜美减龄 | 日常、约会 |
| **H. 百褶型** | Pleated Mini | 褶裥展开，但保持短款 | 学院风、减龄 | 学院风、日常 |

### 1.3 按腰线位置分类

| 腰线 | 英文 | 效果 |
|------|------|------|
| **超高腰** | Ultra High-waist | 肚脐以上，极致拉长腿部，腰细感最强 |
| **高腰** | High-waist | 肚脐位置，最常用，平衡感最好 |
| **中腰** | Mid-rise | 肚脐以下，自然腰线，最日常 |
| **低腰** | Low-rise | 髋骨位置，Y2K复古感，挑战身材 |

## 二、面料科学（核心知识）

### 2.1 面料分类与特性

| 面料 | 弹力 | 厚度 | 光泽 | 塑形力 | AI生成难度 |
|------|------|------|------|--------|-----------|

| **弹力缎面** | ⭐⭐⭐⭐ | 中 | 高光 | 中高 | 中（反光处理） |
| **PU皮革** | ⭐⭐⭐ | 中-厚 | 半光/高光 | 高 | 中（质感还原） |
| **真皮** | ⭐⭐ | 厚 | 自然光泽 | 高 | 高（褶皱复杂） |
| **牛仔** | ⭐⭐ | 厚 | 哑光 | 中 | 低 |
| **西装面料** | ⭐⭐ | 中 | 哑光 | 中高 | 低 |
| **丝绒** | ⭐⭐⭐ | 中 | 哑光→高光 | 中 | 高（光影复杂） |
| **PVC/漆皮** | ⭐ | 厚 | 极高光 | 极高 | 中（反光处理） |
| **网纱覆盖** | ⭐⭐⭐⭐ | 薄 | 半透明 | 低 | 高（层次感） |
| **弹力太空棉** | ⭐⭐⭐⭐ | 中厚 | 哑光 | 高 | 低（结构清晰） |

| 面料 | 最佳风格 | 避免风格 |
|------|----------|----------|
| 弹力针织 | 日常·运动·极简 | 正式晚宴 |

| PU皮革 | 夜店·摇滚·前卫 | 甜美·学院 |
| 真皮 | 高端·极简·质感 | 学院·甜美 |
| 牛仔 | 街拍·休闲·美式 | 正式晚宴 |
| 西装面料 | 职场·知性·正式 | 夜店·运动 |
| 丝绒 | 秋冬·复古·奢华 | 夏季·运动 |
| PVC/漆皮 | 未来感·夜店·前卫 | 日常·职场 |
| 太空棉 | 极简·运动·街头 | 复古·正式 |

### 2.3 面料描述词库（AI生图用）

**弹力针织**：
```
stretchy knit fabric, matte finish, body-conforming elasticity,
soft jersey texture, natural drape with tension
```

**弹力缎面**：
```
stretch satin fabric, lustrous sheen, light-catching surface,
smooth silky texture, elegant reflective quality
```

**PU皮革**：
```
faux leather, semi-gloss finish, structured texture,
smooth surface with slight grain, modern edge
```

**真皮**：
```
genuine leather, natural grain texture, supple hand-feel,
rich patina, organic surface variation
```

**牛仔**：
```
stretch denim, classic indigo texture, visible twill weave,
casual rugged texture, fading at stress points
```

**丝绒**：
```
velvet fabric, plush pile texture, light-absorbing deep color,
rich tactile surface, shimmering at fold edges
```

**PVC/漆皮**：
```
patent leather or PVC, mirror-like high-gloss finish,
liquid reflection surface, futuristic sheen
```

**太空棉**：
```
scuba knit fabric, neoprene-like structure, smooth matte surface,
holds shape without wrinkling, architectural body
```

## 七、AI生图优化指南

### 7.1 稳定出图的关键词组合

**最稳定（黑色针织）**：
```
black high-waisted stretch knit bodycon mini skirt,
fitted silhouette hugging the hips,
matte fabric texture, above-knee length
```

**次稳定（缎面）**：
```
black high-waisted satin bodycon mini skirt,
lustrous sheen catching the light,
smooth fitted silhouette, elegant hemline
```

**需注意（皮革）**：
```
black high-waisted faux leather pencil skirt,
semi-gloss structured texture,
fitted hip-hugging design, modern edge
```

### 7.2 常见AI畸变与对策

| 畸变问题 | 原因 | 对策描述词 |
|----------|------|-----------|
| 裙子变成裤子 | 模型混淆 | `skirt NOT pants NOT shorts NOT trousers` |
| 裙摆过长 | 位置不准 | `above-knee length, mini skirt length, upper thigh hemline` |
| 腰线位置错 | 腰线模糊 | `high-waisted at natural waistline, navel-level waistband` |
| 面料质感丢失 | 描述不足 | 加具体面料词 `stretch satin / knit jersey / faux leather` |
| 臀部比例失调 | 过度强调 | `natural hip curve, balanced proportion, realistic body` |
| 裙子飘起来 | 动态干扰 | `stationary fabric, body-hugging drape, gravity-appropriate` |

### 7.3 高级描述词组合

**想要显瘦效果**：
```
streamlined silhouette, elongated body line,
high-waisted design creating vertical emphasis,
dark color palette, fitted but not restrictive
```

**想要曲线效果**：
```
body-contouring fabric, natural waist-to-hip curve,
smooth rounded hip line, balanced proportion,
elegant feminine silhouette
```

**想要高级感**：
```
minimalist design, clean lines, premium fabric texture,
subtle sheen, refined tailoring, understated elegance
```
