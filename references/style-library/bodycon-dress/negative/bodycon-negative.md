cheap clubwear, shiny plastic fabric, overly glossy latex,
vulgar pose, explicit nudity, see-through exposure,

## 按场景微调

### 极简棚拍

```
标准Negative + colorful background, busy props,
warm color cast, vintage filter
```

### 酒店场景

```
标准Negative + messy room, cluttered background,
harsh flash, overexposed windows
```

### 街拍

```
标准Negative + empty street, no people,
rain, overexposed sky, lens flare
```

### 晚宴

```
标准Negative + bright overhead lighting,
casual clothing on background people,
modern furniture visible
```

### 新中式

```
标准Negative + western furniture, modern decor,
neon lights, club atmosphere
```
