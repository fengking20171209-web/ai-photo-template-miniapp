## 01. CINEMATIC_WIDESCREEN — 电影宽银幕

**编码**：cinematic-widescreen
**画幅比**：2.39:1（变形宽银幕）
**参考电影**：《银翼杀手2049》《黑客帝国》

### 构图特点
- 超宽画面比例，横向空间感极强
- 人物居中或三分之一位置
- 大量负空间营造孤独感或宏大感
- 前景元素（门框、窗框、建筑线条）增加层次
- 色调偏冷或去饱和

### 光影要求
- 低调照明，大面积阴影
- 单一方向性强的主光
- 背景灯光作为点缀

### Prompt 描述词
2.39:1电影宽银幕构图，超宽画面横向空间感，
人物居中或三分之一位置，大量负空间营造氛围，
前景框架元素增加层次，电影级色调处理，
变形宽银幕镜头的椭圆光斑虚化效果

### 适配情绪：cold, dominant, editorial
### 适配服装：cyberwear, lace-black, silk-black
### 适配场景：cyber-showcase, urban-night, black-studio

## 02. CINEMATIC_CLOSE — 电影面部特写

**编码**：cinematic-close
**画幅比**：16:9（标准电影）
**参考电影**：《黑天鹅》《坠落的审判》

### 构图特点
- 面部占画面 60-80%
- 眼睛在画面上三分之一焦点位置
- 浅景深极锐利的面部对焦
- 背景完全虚化成色块
- 面部光影层次丰富，强调眼神

### 光影要求
- 伦勃朗光或蝴蝶光
- 眼神光必须存在（瞳孔中的光点）
- 面部明暗交界线清晰

### Prompt 描述词
16:9电影面部特写构图，面部占画面核心区域，
眼睛在视觉焦点位置有眼神光，浅景深极锐利，
伦勃朗光面部光影层次丰富，明暗交界线清晰，
电影级面部特写的情感张力，瞳孔反光捕捉

### 适配情绪：mysterious, confident, cold
### 适配服装：不重要（面部为主）
### 适配场景：任意（面部特写忽略背景）

## 03. CINEMATIC_WALKING — 电影行走长镜头

**编码**：cinematic-walking
**画幅比**：2.39:1 或 16:9
**参考电影**：《花样年华》《迷失东京》

### 构图特点
- 人物在画面中行走，有明确方向感
- 背景有纵深透视线条（走廊、街道、T台）
- 环境叙事感强，场景讲述故事
- 可以有轻微运动模糊暗示动态
- 色调温暖或冷调均可，取决于叙事情绪

### 光影要求
- 环境光为主，自然或半自然
- 人物身上的光与环境光融合
- 可以有窗户光、路灯、霓虹灯等环境光源

### Prompt 描述词
电影行走长镜头构图，人物在画面中行走有方向感，
背景纵深透视线条引导视线，环境叙事感强烈，
轻微运动模糊暗示动态，电影级色调处理，
场景与人物共同讲述故事的画面感

### 适配情绪：mysterious, confident, editorial
### 适配服装：silk, lace, cyberwear（流动感面料效果最佳）
### 适配场景：urban-night, oriental-courtyard, hotel-bedroom

## 04. CINEMATIC_REFLECTION — 电影镜面反射

**编码**：cinematic-reflection
**画幅比**：1:1 或 4:5（正方形/竖版）
**参考电影**：《穆赫兰道》《暖暖内含光》

### 构图特点
- 利用镜面、水面、玻璃等反射面
- 真实与反射形成对称或不对称构图
- 双重影像增加叙事层次和神秘感
- 可以有反射中的失真或模糊
- 画面分割（反射面作为分割线）

### 光影要求
- 反射面的光影与真实面有差异
- 可以有一侧暖一侧冷的对比色温
- 反射中的光影可以更梦幻或更锐利

### Prompt 描述词
电影镜面反射构图，利用镜面水面玻璃反射，
真实与反射形成对称或不对称双重影像，
反射面作为画面分割线，增加叙事层次，
电影级镜面反射的梦幻与现实交织效果，
反射中的光影可以更梦幻或更超现实

### 适配情绪：mysterious, editorial, luxurious
### 适配服装：silk, lace-nude, cyberwear-pvc
### 适配场景：hotel-bedroom, oriental-courtyard, infinity-pool
