## 关键搭配规律

1. **蕾丝 + 盘发/卷发** = 经典优雅组合（princess-half, low-bun, shark-clip, french-curl）
2. **丝绸 + 长发/盘发** = 高级慵懒组合（wet-wave, center-straight, low-bun）
3. **泳装 + 露出发型** = 性感活力组合（high-ponytail, bun-clean, wet-wave）
4. **运动 + 高扎发** = 飒爽利落组合（high-ponytail, twin-ponytails）
5. **赛博 + 造型感发型** = 未来前卫组合（cyber-silver, cyber-wet）
6. **裸感 + 自然发型** = 高级极简组合（center-straight, low-bun, shark-clip）
