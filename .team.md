# Multi-Agent Team Definition — AI Photo Template MiniApp

> **团队名称：** `ai-photo-agent-team`  
> **版本：** 1.0.0  
> **创建时间：** 2026-06-05

---

## 1. 团队角色

| 角色 | Agent ID | 职责 | 状态机 |
|------|----------|------|--------|
| **Coordinator** | `coordinator-001` | 统一调度所有 Agent 和触发器 | `idle` → `introspecting` → `approving` → `idle` |
| **Generator** | `generator-001` | Prompt 生成和图像生成 | `idle` → `working` → `completed`/`error` → `idle` |
| **Reviewer** | `reviewer-001` | Prompt 质量审查 | `idle` → `reviewing` → `approved`/`rejected` → `idle` |
| **Introspector** | `introspector-001` | 自省分析和修正建议 | `idle` → `introspecting` → `approved`/`rejected` → `idle` |
| **Syncer** | `syncer-001` | GBrain 数据同步 | `idle` → `syncing` → `idle` |

---

## 2. 协作协议

### 2.1 GBrain 集成规则

| 规则 | 执行者 | 说明 |
|------|--------|------|
| `gbrainFirst` | 所有 Agent | 任务开始前查询 GBrain 获取历史参考 |
| `recordEverything` | Coordinator | 所有决策、发现、变更记录到 GBrain |
| `syncAfterWrite` | Syncer | 写入 GBrain 后执行 sync |
| `selfApproving` | Introspector | 任务完成后触发自省 |
| `autoSelfApproving` | Coordinator | 自动自省并存储 |

### 2.2 事件驱动协作

```
Generator → [task_completed] → Coordinator
                                ↓
                         [trigger introspection]
                                ↓
                         Introspector → [analysis]
                                ↓
                    ┌───────────┴───────────┐
                    ↓                       ↓
              [passed]              [needs_correction]
                    ↓                       ↓
              [approved]            [corrector attempts]
                    ↓                       ↓
              [sync to GBrain]      [review or rollback]
```

---

## 3. 触发器矩阵

| 触发器 | 触发条件 | 执行 Agent | 动作 |
|--------|----------|------------|------|
| `auto-self-approving` | 任务完成 | Introspector | introspect, sync_to_gbrain |
| `failure-introspection` | 任务失败 | Introspector | introspect, correct, notify |
| `prompt-quality-check` | 质量 < 70 | Reviewer | introspect, correct, notify |

---

## 4. 降级策略

| 场景 | 降级行为 |
|------|----------|
| GBrain 不可达 | 本地自省，不记录 timeline |
| 自省超时 | 标记为 `needs_review`，等待人工介入 |
| 修正失败（达到最大次数） | 标记为 `needs_review`，保留错误日志 |
| 回滚失败 | 标记为 `error`，保留完整上下文 |

---

## 5. 通信协议

### 5.1 EventBus 订阅

| 订阅者 | 订阅事件 | 响应 |
|--------|----------|------|
| Coordinator | `task_completed`, `task_failed` | 触发自省 |
| Coordinator | `trigger_fired` | 调度后续动作 |
| Introspector | `introspection_started` | 执行分析 |
| Syncer | `sync_to_gbrain` | 执行同步 |

### 5.2 消息格式

```json
{
  "eventId": "uuid",
  "type": "task_completed",
  "sourceAgent": "generator-001",
  "targetAgent": "coordinator-001",
  "timestamp": "2026-06-05T01:06:14.000Z",
  "payload": {
    "taskId": "task_...",
    "status": "completed"
  },
  "priority": 10
}
```

| 指标 | 说明 |
