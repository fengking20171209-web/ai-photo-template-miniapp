## 一、产品层已就绪

| 模块 | 状态 | 对 Round 6 的价值 |
|------|:----:|-------------------|
| 模板发现 | ✅ | 真 API 接入后，用户能快速找到想生成的模板 |
| 价格档位 | ✅ | 付费模板可直接对接真 API，免费模板继续 mock |

| 模块 | 状态 | 对 Round 6 的价值 |
|------|:----:|-------------------|

## 三、唯一阻塞项

| 阻塞项 | 状态 | 解决方案 |
|--------|:----:|----------|
| SenseNova 凭证 | ❌ | 需获取有效的 Access Key / Secret Key，配置到 `.env` |

## 四、进入 Round 6 后的第一件事

验证凭证可用性：

```bash
# 1. 配置 .env
SENSENOVA_ACCESS_KEY=your_key
SENSENOVA_SECRET_KEY=your_secret

# 2. 测试认证
python backend/scripts/test_sensenova.py

# 3. 期望结果
# HTTP 200，返回 token 或生成任务 ID
# 不再报 401 Forbidden
```

## 五、Round 6 的核心目标（预设）

1. **真 API 接入**：SenseNova 图像生成接口对接
2. **付费解锁**：付费模板调真 API，免费模板保持 mock
3. **结果下载**：真图返回后支持下载/分享
4. **成本监控**：记录每次 API 调用的成本，支持运营分析
