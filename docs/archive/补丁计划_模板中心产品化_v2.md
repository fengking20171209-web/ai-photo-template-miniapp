# 补丁计划 — 模板中心产品化

## 【目标】

完成模板中心核心功能闭环：搜索、分类筛选、收藏、最近使用。保持 mock 模式，不接入真 API。

## 【范围】

**包含**：
- 前端搜索接入后端 API（关键词搜索 + 分类筛选联动）
- 模板中心快捷入口（热门推荐 / 我的收藏 / 最近使用）
- 最近使用后端接口（基于 UserEvent 埋点表）
- 生成埋点修复（补充单个生成事件）
- 模板 tags 自动补全（支持标签搜索）

**不包含**：
- 真 API 接入（SenseNova 凭证问题未解决）
- COS 上传/存储
- 支付系统
- 用户账户系统
- 抖音小程序接入

## 【每个文件准备改什么】

### `public/app.js`（Round 1 + Round 2 + Round 3，累计 3 处改动）

**改动 1 — 搜索接入后端 API（Round 1）**：
- `renderTemplateList()` 从同步函数改为 `async function`
- 函数体内：当 `state.searchQuery` 非空时，调 `GET /templates/search?q=...&page=1&limit=100`，用返回的 `items` 渲染列表
- 当 `searchQuery` 为空时，保持现有本地分类过滤逻辑
- 所有调用 `renderTemplateList()` 的地方加 `await`（共 5 处）
- `templateSearch` input 事件加 400ms debounce，停止输入后才调 `renderTemplateList()`

**改动 2 — 快捷入口逻辑（Round 2）**：
- 新增 `renderQuickFilters()` 函数：渲染 🔥/⭐/🕐 三个按钮，点击后设置 `state.quickFilter`
- `renderTemplateList()` 内新增 `quickFilter` 分支：
  - `'recommended'` → 调 `/templates/recommended?limit=12`
  - `'favorites'` → 本地过滤 `state.favorites`
  - `'recent'` → 调 `/templates/recently-used?limit=12`
- 搜索/分类筛选时自动清除 `quickFilter` 状态

**改动 3 — 生成埋点（Round 3）**：
- `generateFromTemplate()` 中，在生成成功（`result.status !== 'failed'`）后插入 `trackEvent('generate', { template_id: templateId })`

### `backend/routers/templates.py`（Round 2，1 处改动）

- 新增 `GET /templates/recently-used` 端点：
  - 查询 `UserEvent` 表过去 30 天的 `click`/`generate`/`batch_generate` 事件
  - 按 `template_id` 分组，取 `max(created_at)` 倒序
  - limit 默认 8
  - 返回模板摘要 + `last_used` 时间戳

---

### `scripts/enrich_templates.py`（Round 3，新建）

- 扫描 `templates/*.json`
- 对每个模板：基于 `category` + `style` + `scene` + `clothing` 提取关键词，生成 `tags` 数组（如 `"古风美女"` → `["古风", "美女", "写真"]`）
- 将 `tags` 写回 JSON 文件
- 输出处理统计（成功/失败数）
