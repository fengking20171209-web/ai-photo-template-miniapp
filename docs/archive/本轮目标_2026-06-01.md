# 本轮目标 — 2026年6月1日

## 核心目标

**完成"产品内容层"闭环，使模板系统从"能用"变为"完整可用"。**

具体拆解为三个子目标：

### 目标 1：修复数据不一致（分类硬编码 + 模板结构）
- **问题**：代码里只声明 6 个分类，磁盘上实际存在 9 个分类的模板；30 个模板使用非标准字段结构；1 个模板 `template_id` 和 `category` 错标
- **结果**：分类硬编码扩展至 10 个；`concept_neo-chinese-bodycon.json` 重写为标准格式；30 个旧模板完成十层→八层字段迁移
- **验收标准**：`npm run list` 加载 42 个模板零报错，`npm run check` 类型检查通过

### 目标 2：扩充模板库（从 references 提炼新产品内容）
- **来源**：`references/awesome-gpt-image-2-API-and-Prompts/cases/`
- **新增**：5 个模板（3 个人像写真 + 2 个产品海报）
- **新增分类**："人像写真"（从 portrait 案例中独立出来，不与"模特大赛"混用）
- **验收标准**：新模板可通过 `npm run generate <id>` 正常输出 `output/prompt.txt`

### 目标 3：前端闭环（mock 模式下跑通完整用户流程）
- **问题**：前端调用 `/generate/generate` 传 `{prompt, size, n}`，但后端实际接口是 `/generate` 只接受 `{template_id}`
- **修复**：对齐前后端接口，前端改为"选模板 → 一键生成写真"流程
- **验收标准**：浏览器访问 `http://127.0.0.1:3000` → 选模板 → 点击"生成写真" → 看到任务状态 + prompt 预览
