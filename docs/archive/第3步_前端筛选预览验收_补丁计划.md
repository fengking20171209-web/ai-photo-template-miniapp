# 补丁计划 — 第 3 步：前端筛选/预览验收

## 1. 背景与目标

模板数据层已就绪（48+ 模板 / 10 分类），前端已实现分类筛选和 mock 生成闭环。本步骤目标是**全面验收前端交互体验**，确保筛选、详情展示、生成、预览全流程无阻塞。

**目标**：
1. 修复已知路径错误（`/api/templates` → `/templates`）
2. mock 模式下结果区信息充实（任务元信息 + prompt 摘要）
3. 前端功能全面验收通过

## 2. 修改范围

| 文件路径 | 操作 | 影响面 |
|----------|:----:|--------|
| `public/app.js` | 修改 | API 路径修复 + 结果展示增强 |
| `public/index.html` | 修改 | 结果区 DOM 结构 |
| `public/styles.css` | 修改 | 结果区样式 |

**本轮修改文件数：3 个**，符合工程纪律。

## 3. 不会修改的内容

`.env` / COS / 真 API / 依赖 / 删除 / 格式化 / 超过 3 个文件

## 7. 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|:----:|:----:|----------|
| `navigator.clipboard` 在非 HTTPS 环境受限 | 低 | 中 | 降级：临时 textarea + `document.execCommand('copy')` |
| 浏览器缓存导致旧版本 | 低 | 低 | 强制刷新（Ctrl+Shift+R）或无痕模式验证 |
