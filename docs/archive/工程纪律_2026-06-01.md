**开始前必须先输出补丁计划，不要直接修改文件。**

**模板扩充节奏：每类 3 个，总计 9 个 / 轮。**

理由：刚好覆盖三大产品方向（电商产品类、人像写真类、古风国风类），验证分类、筛选、展示链路，不至于一次改太大。

**修改后必须主动跑最小验证命令，不等用户提醒。**

| 改动类型 | 必须主动跑的命令 |
|----------|-----------------|
| TypeScript 代码修改 | `npm run check` |
| 模板新增/修改 | `npm run list && npm run generate <template_id>` |
| 前端代码修改 | `npm run api` + 浏览器手动验证 |
| Python 后端修改 | `uv run python -m pytest backend/tests/` |
| 任何编译型改动 | `npx tsc` |

**如果项目缺少常用脚本，自动执行等效替代命令，不报错停止。**

| 用户要求的命令 | 实际执行的替代命令 | 说明 |
|:--:|-------------------|------|
| `npm run typecheck` | `npm run check` 或 `npx tsc --noEmit` | 项目中无 `typecheck` 脚本 |
| `npm run build` | `npx tsc` | 项目中无 `build` 脚本 |

**如果忘记主动跑，用户提醒时必须立刻补跑，不得拖延。**
