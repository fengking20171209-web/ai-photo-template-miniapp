# 后续工作要求

## 一、工程纪律（已确立，严格执行）

1. **先输出补丁计划，再执行修改**
2. **每轮最多修改 3 个文件**
3. **不修改 `.env`**
4. **不上传 COS**
5. **不接入真生图 API**（维持 mock）
6. **不重装依赖**
7. **不删除文件**
8. **不格式化全项目**
9. **模板扩充节奏：每类 3 个 / 总计 9 个 / 轮**

## 二、模板质量要求

1. **字段结构 100% 对齐规范**：template_id / category / title / version / ratio / face_lock / style / scene / clothing / prompt_blocks（8 字段）/ options（3 字段）/ negative_prompt
2. **每个模板必须字段完整**：顶层 12 字段 + prompt_blocks 8 字段 + options 3 字段，全部非空
3. **template_id 必须与文件名一致**
4. **命名不得重复**：template_id 和 title 在全局范围内必须唯一
5. **category 必须和 `templateSchema.ts` 类型定义一致**：新增分类时，必须同步修改 `src/types/template.ts` + `src/templates/templateSchema.ts`，否则校验拒绝加载
5. **prompt_blocks 必须结构化**：固定 8 个字段（subject / face / clothing / scene / lighting / camera / quality / commercial_use），顺序一致，内容结构化
6. **prompt_blocks 必须使用中文**（参考库英文 prompt 需翻译提炼）
6. **negative_prompt 不少于 5 项**
7. **新增模板必须通过 `npm run generate` 验证**

## 三、代码修改要求

1. **修改后必须运行最小验证命令，不跳过**：
   - TypeScript 代码修改 → `npm run check`
   - 模板新增/修改 → `npm run list && npm run generate <template_id>`
   - 前端代码修改 → `npm run api` + 浏览器手动验证
   - Python 后端修改 → `uv run python -m pytest backend/tests/`
2. **模板加载必须正常**：`npm run list`
3. **前端修改需验证浏览器交互**
4. **Python 后端修改需验证 FastAPI 服务**

## 四、文档同步要求

1. **修改模板分类或结构后，同步更新 `docs/template_system.md`**
2. **修改工程纪律后，同步更新 `工程纪律_*.md`**
3. **每轮结束后更新 `后续待办_*.md`**
