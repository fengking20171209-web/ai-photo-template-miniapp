# 用户旅程 — 完整闭环

```
模板库 → 搜索筛选 → 收藏 → 上传 → mock 生成 → 结果展示
```

## 步骤 1：模板库

- 打开 `http://localhost:3000`
- 左侧显示 54 个模板卡片
- 每个卡片显示：分类、标题、风格、价格标签（免费/¥X）

## 步骤 2：搜索筛选

- **搜索**：输入关键词（如"古风""汉服"），400ms debounce 后列表刷新
- **分类筛选**：点击"古风美女""人像写真"等分类，即时过滤
- **快捷入口**：🔥 热门 / ⭐ 收藏 / 🕐 最近，一键切换视图

## 步骤 3：收藏

- 点击模板卡片右下角的 ★
- ★ 变为金色，加入收藏列表
- 刷新页面后收藏状态保留（localStorage）
- 点击"⭐ 收藏"快捷入口查看全部收藏

## 步骤 4：上传

- 点击模板卡片进入详情页
- 上传本地照片（支持拖拽/点击选择）
- 实时预览上传图片

## 步骤 5：mock 生成

- 免费模板：点击"生成写真"
- 付费模板：点击"解锁并生成"
- 状态流：提交中 → 排队中 → 生成中（带进度条）→ 完成
- 实际调用 `/generate` 接口，返回 mock 结果

## 步骤 6：结果展示

- 结果横幅显示"生成完成 · X.Xs · 免费版/预览版"
- 图片占位区展示（mock 模式）
- Prompt 预览区展示完整提示词
- 一键重新生成
- 生成记录自动进入"作品集"画廊

---

**状态**：✅ 全流程已闭环，mock 模式稳定运行
