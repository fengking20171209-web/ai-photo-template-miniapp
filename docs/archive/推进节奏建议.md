## 节奏控制要点

| 要点 | 说明 |
|------|------|
| **每轮只推进一个主题** | 前端 / 模板 / 债务 / API，不混做 |
| **每轮结束后必须验收** | `npm run check` + `npm run list` + 手动验证 |
| **模板扩充不超过 3 个/轮** | 控制质量，避免批量生产低质模板 |
| **真 API 测试单列一轮** | 不与其他改动混做，便于问题定位 |
| **COS/部署相关全部暂缓** | 本地功能未稳定前不推进 |
