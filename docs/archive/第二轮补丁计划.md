# 补丁计划 — 第二轮

## 1. 背景与目标

前端 mock 闭环已跑通，但存在两处体验瑕疵：
1. `public/app.js` 调用 `/api/templates`，但后端实际路由是 `/templates`，导致模板列表可能加载失败
2. mock 模式下结果区仅显示"✓ 生成成功"和空白图片占位，用户体验空洞

**目标**：修复路径错误，增强 mock 模式下结果区的信息展示（任务元信息 + prompt 摘要）。

## 2. 修改范围

| 文件路径 | 操作 | 影响面 |
|----------|:----:|--------|
| `public/app.js` | 修改 | 前端 API 路径 + 结果展示逻辑 |
| `public/index.html` | 修改 | 结果区 DOM 结构 |
| `public/styles.css` | 修改 | 结果区样式 |

**本轮修改文件数：3 个**，符合工程纪律。

## 3. 不会修改的内容

`.env` / COS / 真 API / 依赖 / 删除 / 格式化 / 超过 3 个文件

## 4. 具体变更内容

### 文件 A：`public/app.js`

**变更前：**
```javascript
const data = await api('/api/templates');
```

**变更后：**
```javascript
const data = await api('/templates');
```

**变更前：**
mock 模式下 `imageUrls.length === 0`，结果区空白。

**变更后：**
- `imageUrls` 为空时显示提示："mock 模式 — prompt 已就绪，接入真 API 后显示图片"
- 展示任务元信息：`task_id`、`template_id`、`category`、`status`
- 展示 `image_request.request_body.prompt` 前 200 字 + "展开/收起"按钮
- 添加"复制 prompt"按钮，使用 `navigator.clipboard.writeText`

### 文件 B：`public/index.html`

**变更前：**
结果区只有图片占位、`resultPromptBlock`（需异步加载）、`resultActions`（重新生成按钮）。

**变更后：**
结果区新增：
- `.result-meta-card`：任务信息卡片（task_id / template / category / status）
- `.result-prompt-card`：prompt 摘要卡片（等宽字体、代码块样式、复制按钮）
- `.mock-hint`：mock 模式提示文案

### 文件 C：`public/styles.css`

**变更前：**
无结果区卡片化样式。

**变更后：**
新增：
- `.result-meta-card`：浅色背景、圆角、小字网格布局
- `.result-prompt-card`：等宽字体、深色代码块背景、右上角复制按钮
- `.btn-copy`：小尺寸、悬浮定位
- `.mock-hint`：灰色斜体、居中

## 7. 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|:----:|:----:|----------|
| `navigator.clipboard` 在非 HTTPS 环境下受限 | 低 | 中 | 降级：临时 textarea + `document.execCommand('copy')` |
| `image_request.request_body.prompt` 路径不存在 | 低 | 低 | 使用可选链 `?.` + fallback 文本 |
