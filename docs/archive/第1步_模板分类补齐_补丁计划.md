# 补丁计划 — 第 1 步：模板分类补齐

## 1. 背景与目标

第一轮模板扩充后，古风国风类实际新增 2 个（大唐仕女、武侠侠女），缺 1 个未达到"每类 3 个"的节奏目标。

**目标**：补齐古风国风类第 3 个模板，使三大产品方向（电商/人像/古风）每类都达到 3 个新模板。

## 2. 修改范围

| 文件路径 | 操作 | 影响面 |
|----------|:----:|--------|
| `templates/ancient_song_elegant.json` | 新增 | 古风国风类模板数据 |

**本轮修改文件数：1 个**（远低于 3 个上限，留有余量）。

## 3. 不会修改的内容

`.env` / COS / 真 API / 依赖 / 删除 / 格式化 / 超过 3 个文件
