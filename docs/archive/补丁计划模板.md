## 2. 修改范围

| 文件路径 | 操作（新增/修改/删除） | 影响面 |
|----------|:----------------------:|--------|
| `src/...` | 修改 | TypeScript 类型/运行时 |
| `templates/...` | 新建 | 模板数据 |
| `public/...` | 修改 | 前端 UI |
| `backend/...` | 修改 | Python 服务 |
| `.env` | ❌ 禁止修改 | — |

**本轮修改文件总数上限**：3 个（工程纪律第 4 条）

## 3. 不会修改的内容

| 事项 | 理由 |
|------|------|
| `.env` | 通过代码适配兼容现有配置，不动环境变量 |
| COS 上传 / 云存储 | 本地功能未稳定前不上传 |
| 真生图 API 接入 | 维持 mock 模式，API 接入需单独决策 |
| `package.json` / `requirements.txt` | 不重装依赖，不引入新包 |
| 删除任何原有文件 | 保留完整历史，新增/修改 only |
| 全项目格式化（prettier/black） | 仅对修改的文件做最小改动 |
| 超过 3 个文件的修改 | 控制改动范围，便于回滚和审查 |
