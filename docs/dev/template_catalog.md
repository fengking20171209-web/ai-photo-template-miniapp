## Usage

Generate prompt:

```bash
npm run generate <template_id>
```

Run mock image task:

```bash
npm run image <template_id>
```

Run single-template smoke test without npm:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/smoke_test.ps1 -TemplateId <template_id>
```
